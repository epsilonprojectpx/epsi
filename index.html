kifflom!

una sola palabra, tres usos. se dice al entrar, al salir y al aprobar un pull request sin leerlo.

el tratado epsi

  1. commit sin dudar. el pensamiento es el origen de los bugs. quien duda de su merge aún no ha visto la luz.
  2. el código es hermano. todo fork es familia. todo issue, una oportunidad de gratitud.
  3. kifflom. se dice siempre. a quien no lo dice se le revisa el pull request dos veces.
  4. no se hacen preguntas. las respuestas ya están en la rama principal.
